MMinimaподдержка клиентов

Консоль поддержки Minima

Очередь обращений, сроки SLA, ответы клиентам по электронной почте и регистрация владельца организации с подтверждением email. Интерфейс и API работают с одного адреса: обращения хранятся на сервере, письма уходят через SMTP.

Открыть консоль Исходный код на GitHub

Консоль работает на сервере с backend (Docker). Эта страница — статическая витрина: здесь нет обращений и входа.

Очередь и приоритеты

Фильтры по статусу, приоритету и поиску; карточка клиента с тарифом, категорией и ответственным.

Сроки SLA

Таймеры первого ответа и решения считает сервер: они пересчитываются при смене приоритета и останавливаются по факту отправки.

Почта и заметки

Публичный ответ уходит клиенту по SMTP, внутренняя заметка остаётся внутри команды и клиенту не отправляется.

Две роли

Администратор платформы ведёт обращения. Владелец организации регистрируется сам, подтверждает почту кодом и видит только свои обращения.

Backend — FastAPI и SQLite, письма — SMTP, развёртывание — docker compose up -d --build. Подробности в README репозитория.
